功能介绍
功能说明
格式化按 2 空格、4 空格或 Tab 缩进重新排版，嵌套结构一目了然。
压缩去除全部空白得到紧凑单行，并显示压缩前后的体积对比。
校验检查 JSON 合法性，报错给出中文原因和行列号，点击可定位。
拖放导入拖入 .json / .txt 文件即可载入，单文件最大 10MB。
复制下载结果一键复制到剪贴板，或下载为 data.json。
隐私保护全程在浏览器本地处理，不上传、不注册，关闭页面即清除。

常见问题
问题答案
数据会上传到服务器吗？不会。全程在浏览器本地处理，可断网使用。
支持哪些输入方式？直接粘贴、拖入 .json / .txt 文件，或点击示例体验。
文件大小有限制吗？拖放文件上限 10MB；粘贴超大文本会有稍慢提示但仍可处理。
支持注释或单引号吗？不支持。JSON 标准要求双引号且不允许注释，报错会说明原因。
需要注册登录吗？不需要，打开网页即可使用。
