广告位
功能介绍
功能说明
双向转换文本与 Base64 互相转换，边输入边出结果，也可手动输入或点「载入示例」快速试用。
自动判定自动区分明文、Base64、Data URI 与三段式 JWT，分别编码或解码；判错可手动锁定方向。
方向锁定自动 / 只编码 / 只解码三档，锁定后不再猜测，无需刷新页面。
输出格式编码结果可输出为纯 Base64，或带 data:…;base64, 前缀的 Data URI，后者可直接用作图片地址。
折行宽度输出可选不折行、每 76 或每 64 字符折行，适配 MIME 邮件与 PEM 证书。
URL-safe一键切换 URL-safe 字符集（- 与 _），产物可直接放进链接与文件名。
填充开关可保留或去掉末尾填充符 =，去掉后仍可被本工具重新解出。
实时统计输入字符、UTF-8 字节、输出长度与体积变化四项实时更新。
文件转 Base64拖入、选择或粘贴文件，得到纯 Base64 或 Data URI，并显示类型、大小、图片尺寸与编码长度。
下载文件解出二进制时进入文件状态，按类型或文件头猜扩展名；认不出会弹框让你填 1–8 位字母数字，下载名形如 base64-decoded.png。
粘贴预览直接 Ctrl+V 粘贴截图，在导入区内显示缩略图与尺寸；HEIC / HEIF 浏览器不能内联预览，改用文件图标但仍可正常编码。
嵌入片段图片类数据可一键复制 img 标签或 CSS background-image 片段，粘贴即用。
大输入保护输入超过 256K 字符时停止自动转换，点「转换」再执行；结果超过 200K 字符只显示前 50K，复制与下载始终取完整内容。
隐私本地纯前端本地运行，不上传任何内容，断网也能用；只有方向、折行等选项偏好写进本机 localStorage。
用法与语法说明
项说明
什么是 Base64把任意字节按 6 位一组映射到 A–Z、a–z、0–9、+、/ 共 64 个字符，末尾用 = 补齐到 4 的倍数。
自动判定顺序依次判断：data:…;base64, 前缀 → 三段式 JWT → 长度合规且能解出 UTF-8 文本的 Base64 → 其余按明文编码；解出二进制则进入文件状态。
文件类型识别纯 Base64 没有 MIME 时按文件头魔数判断 PNG、JPEG、GIF、WEBP、PDF、ZIP、GZIP、WOFF、MP3、WAV、OGG、MP4、WASM 等；认不出则留空，下载前询问扩展名。
折行宽度不折行输出一整行；每 76 字符是 MIME 邮件常用宽度，每 64 字符常见于 PEM 证书。
URL-safe 字符集把 + 换成 -、/ 换成 _，避免在 URL 与文件名里被转义；可选去掉填充 =。
保留填充 =标准 Base64 末尾的 = 用于补齐长度；去掉后更短，本工具解码时会自动补回。
Data URI 结构形如 data:[MIME][;base64],数据。编码时可生成 Data URI；解码时按是否带 ;base64 分流：带标记的按 Base64 还原，不带标记的按 URL 编码还原成文本。
中文与 emoji先按 UTF-8 编码成字节再转 Base64，中文与 emoji 都能正确往返，不会乱码。
体积与上限Base64 比原始字节大约多三分之一；单个文件上限 5 MB，编码后约 6.67 MB。
常见问题
问题答案
我的内容会被上传吗？不会。本页是纯前端工具，编码与解码都在浏览器里完成，不向服务器发送输入内容，也不保存正文或文件字节；只有方向、折行、URL-safe、填充等选项偏好会写进本机 localStorage，可随时清空。
为什么解码失败？常见原因：含 Base64 以外的字符（会指出第几个）、去掉空白后长度除 4 余 1、填充符 = 之后还有内容。若数据本身合法、只是解出来不是文本，会进入文件下载状态，不算失败。
自动判定错了怎么办？把「转换方向」拨到「只编码」或「只解码」即可锁定，不需要刷新页面。例如一段恰好全是 Base64 字符的明文被误判时，切到「只编码」就会按明文处理。
怎么把 Base64 还原成图片或文件？切到「只解码」后粘贴内容；解出二进制会显示「已解码为文件」，点「下载文件」保存。类型能从 Data URI 或文件头识别时自动命名，识别不出会弹框让你填扩展名。
支持 HEIC / HEIF 吗？可以导入并编码。浏览器无法把 HEIC / HEIF 画成缩略图，导入区会显示文件图标且不显示尺寸，但编码、复制与下载都正常。
能解析 JWT 吗？三段式 JWT 会被自动识别并给出提示，但本工具不拆分 header / payload；请把需要解码的那一段单独粘贴，再按普通 Base64 处理。
文件大小有限制吗？单个文件上限 5 MB，超过会提示并拒收。文本超过 256K 字符会停止自动转换，点「转换」继续；结果超过 200K 字符只显示前 50K，复制与下载始终是完整内容。
手机上怎么用？小屏为单列卡片流：上方选方向与选项，中间输入，下方看结果与统计。输入后自动转换，点「复制」取结果，点「结果转为输入」可继续反向转换。

清空输入？

将清空输入与结果，此操作不可撤销。

无法判断文件类型

请输入文件扩展名（如 png、pdf、bin），用于命名下载文件。

扩展名只能包含字母和数字，最多 8 位。
