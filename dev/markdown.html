功能介绍
功能说明
实时预览左侧输入 Markdown，右侧即时排版；手机端可切换编辑 / 预览单栏。
语法工具栏粗体、斜体、下划线、删除线、标题一键套用；列表、对齐方式、插入三个下拉菜单，涵盖表格、链接、图片、代码、引用与分割线。
撤销与重做随时撤销、重做，连续输入自动合并为一步；「还原」一键回到载入时的内容。
预览区交互代码块带语言标签，可一键复制、收起展开；表格同样支持复制与收起。
安全渲染预览只构建安全 DOM，不执行任何脚本；链接经协议白名单过滤，恶意内容无法运行。
本地草稿输入自动保存在本机浏览器，下次打开会询问是否恢复内容与光标位置，可随时一键清空。
多种导出复制 Markdown 原文、复制 HTML 源码、下载 .md 文件，随取随用。
实时统计字符、字数、段落数实时更新，写作进度一目了然。
隐私保护纯前端本地运行，不上传任何输入，断网也能使用。
三语界面中文、English、Español 即时切换。

常见问题
问题答案
我的内容会被上传吗？不会。本页是纯前端工具，解析与预览都在你的浏览器里完成，不向任何服务器发送输入内容。草稿只写进本机的 localStorage，可随时一键清空；浏览器阻止本地存储时工具照常可用，只是不保存草稿。
支持哪些 Markdown 语法？支持标题、粗体、斜体、下划线、删除线、有序与无序列表、任务列表、引用、行内代码与代码块、表格（含列对齐）、链接、图片和分割线；下划线与段落对齐为扩展语法。数学公式与流程图暂不支持。
草稿保存在哪里？草稿只保存在本机浏览器的 localStorage 中，不上传、不同步到其他设备。点「清空」即可删除；隐私模式或存储配额满时状态条会提示无法保存。
手机上怎么用？小屏设备提供「编辑 / 预览」切换：默认单栏编辑，点「预览」查看排版，再点「编辑」继续写，数据不会丢失。

清空草稿？

将清空编辑内容并删除本机保存的草稿，此操作不可撤销。
