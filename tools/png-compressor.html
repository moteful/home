功能介绍
功能说明
调色板量化压缩中位切分量化 + Floyd-Steinberg 抖动，将图片色数压到目标档位，体积明显减小，同时保留人眼可接受的画质。
三档预设 + 手动细调均衡（自动判档）/ 高质量 / 极限三档一键套用；颜色数、抖动开关、压缩级别均可手动调整。
对比预览原图 ⇄ 压缩后分割滑块实时对比，逐张显示体积与压缩率。
批量处理 + 打包下载多张 PNG 一次导入，逐张显示压缩结果，一键打包 ZIP 批量下载。
压不小自动兜底压缩后体积未减小时自动提示，并给出提高颜色数、关闭抖动的优化建议。
配置记忆 + 带参分享压缩参数本地记忆；可生成带压缩参数的分享链接，打开即恢复同款设置。
隐私保护100% 本地处理，图片与参数不上传、不注册，关闭页面即清除。

常见问题
问题答案
PNG 压缩后会不会失真？采用有损减色压缩，压缩程度越高画质损失越大。建议使用「均衡」档，并在对比预览中确认效果后再导出。
图片会上传到服务器吗？不会。所有处理都在浏览器本地完成，可断网使用。
支持哪些格式？仅支持 PNG。JPG / WebP 压缩请使用图片工具集。
支持批量处理吗？支持多选导入、批量压缩，结果可一键打包 ZIP 下载。
导出结果可以商用吗？可以。免费、无水印，导出结果无任何使用限制。
需要注册登录吗？不需要，打开网页即可使用。
