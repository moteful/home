功能介绍
功能说明
多种导入方式支持 .svg 文件上传、拖入，以及 SVG 代码直接粘贴，三种方式任选。
颜色与描边一键改图标颜色与描边颜色，描边粗细可调，适配不同视觉场景。
背景与内边距透明或自定义背景色，内边距百分比控制图标留白。
等比缩放16~512 预设画布尺寸，图标始终等比居中，不拉伸变形。
旋转与翻转一键旋转 90/180/270 度，水平、垂直翻转，支持撤销与重做。
多格式导出SVG 矢量与 PNG/JPG/WebP 位图，导出前可放大预览，无水印。
隐私保护100% 本地处理，文件与代码不上传、不注册，关闭页面即清除。
使用场景
网页图标
为网站快速准备 favicon 与按钮图标，统一配色与尺寸。
应用图标
按目标平台导出 16~512 各尺寸 PNG，覆盖大多数商店要求。
UI 素材
设计稿里的 SVG 图标一键换色、调描边，直接导出可用素材。
代码复用
把图标代码整理、统一后复制进项目，保持设计一致性。
常见问题
问题答案
上传的 SVG 会上传到服务器吗？不会。所有处理都在浏览器本地完成，可断网使用。
支持哪些文件格式？导入支持 .svg 文件与 SVG 代码；导出支持 SVG/PNG/JPG/WebP。
多色图标可以改颜色吗？可以。默认整体替换，也可按颜色分组单独修改，灵活适配品牌色。
导出结果可以商用吗？可以。免费、无水印，导出结果无任何使用限制。
需要注册登录吗？不需要，打开网页即可使用。
